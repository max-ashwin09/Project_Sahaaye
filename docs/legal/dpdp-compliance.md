# DPDP Act 2023 Compliance Checklist
- [x] Clear and unconditional consent notices.
- [x] Purpose-specific consent recording.
- [x] Right to withdraw consent.
- [x] Right to access and data portability.
- [x] Right to erasure (account deletion).
- [x] Appointed Grievance Redressal Officer.
- [x] Extra safeguards for children (Section 9).
