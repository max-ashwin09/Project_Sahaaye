# Database Schema & Entity Relationships

See individual SQL schemas in `/database/schema/`:
- `consent_records`: Tracks purpose-specific DPDP consent.
- `deletion_requests`: Tracks right-to-erasure workflows.
- `abuse_reports`: Tracks user and content reports.
- `user_blocks`: Tracks interpersonal safety blocks.
- `moderation_actions`: Moderator enforcement history.
- `appeals`: Fairness and reversal workflow.
- `audit_logs`: Tamper-resistant audit trails.
